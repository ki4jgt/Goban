# Goban — a Pyglet client for online-go.com

A desktop goban for [OGS](https://online-go.com) made with Pyglet. You can watch live games and play
against people or bots. It plays generated ambient music in the background.

## Run

You need Python 3.9 or newer and a graphics driver with OpenGL 3.3, which any computer from about
the last decade has.

**Windows** (PowerShell or Command Prompt):

```bat
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pythonw main.py
```

`pythonw` starts the game without a console window. Use `python` instead if you want to see log
messages.

**macOS:**

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

**Linux:**

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

On a minimal Linux install you may need OpenAL for sound (`libopenal1` on Debian/Ubuntu) and
FFmpeg if you add your own MP3 files. With no working audio device, the game runs silently.

The first launch takes about 10 seconds longer because it generates the music. The result is
cached in:

| Platform | Folder |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Goban\Cache` |
| macOS | `~/Library/Caches/Goban` |
| Linux | `~/.cache/pyglet-goban` |

## What it does

- **Watch:** the lobby lists live games from OGS's realtime server, ordered by player strength.
  The strongest live 19×19 game plays on the centre board. Click any game, or the centre board,
  to open it full-size with clocks, captures and a last-move marker.
- **Play:** sign in with your OGS account. Then you can:
  - use **Find an opponent** to run OGS automatch (board size and pace: blitz, rapid or live), or
  - **challenge a bot** from the list of bots that are online (an unranked live game, 5:00 main
    time plus 5×30s byo-yomi).
  
  Games you have in progress appear under *Your games*. In a game, click an intersection to play,
  and use the Pass and Resign buttons (Resign needs a second click to confirm). During scoring,
  click groups to mark them dead, then *Accept score* or *Resume play*. Undo requests from your
  opponent can be allowed.
- **Messages and notifications:** the **Lobby chat**, **Messages** and **Alerts** buttons at the
  bottom right open a side drawer:
  - *Alerts* lists your OGS notifications (game started, your move, game over, challenges, friend
    requests and so on). Click one to open its game. Click a challenge to accept or decline it.
  - *Lobby chat* shows one of OGS's public rooms, `#global-english` at first. The **Room** button
    at the top switches to any of 31 others: Help, Off Topic, Rengo, Joseki, and language rooms
    from 日本語 and 한국어 to Deutsch and Español. Your choice is remembered. Anyone can read; you
    need to sign in to post. OGS's Arabic, Hebrew, Hindi, Nepali, Bengali and Thai rooms aren't
    offered, because pyglet can't lay out those scripts correctly.
  - *Messages* holds your private conversations. Type a username to start a new one.

  New alerts and private messages pop up as cards at the top right; click one to jump to it. When
  the window is in the background, important ones (your move, challenges, new games, private
  messages) also appear as a desktop notification:

  | Platform | How |
  | --- | --- |
  | Windows | a system toast |
  | macOS | Notification Center |
  | Linux | `notify-send` |

  Each game has its own chat under the clocks, for players and spectators alike.
- **Visuals:** everything is generated in code:
  - a lamp-lit kaya board with a beveled edge and a lacquer sheen that moves with the mouse;
  - slate and shell stones with a soft window reflection, edge glow, translucent shell bands, and
    contact and drop shadows;
  - stones that fall, bounce once and send up a puff of dust and a ripple; captured stones rise
    and break into sparks;
  - behind it all, a night sky with aurora, light shafts, three misty mountain ranges that shift
    with the mouse for depth, falling cherry petals, lantern lights and the odd shooting star;
  - a small American touch: red-rock mesas from the desert Southwest, an amber dusk glow along the
    horizon, and blinking fireflies;
  - a fade in from black at launch.
- **Music:** slow chord pads, sparse pentatonic bells and soft wind, with reverb, as a seamless
  80-second loop. In the second half, a quiet fingerpicked acoustic guitar plays a folk-style
  alternating-bass pattern over the same chords. To play your own music, put `.ogg/.mp3/.wav/.flac` files in a `music/` folder.
  The game looks next to `main.py` (or next to the program, in a stand-alone build), then in your
  user data folder: `%APPDATA%\Goban\music` on Windows, `~/Library/Application Support/Goban/music`
  on macOS, or `~/.local/share/goban/music` on Linux.

## Icon and desktop integration

The app icon is generated by `tools/make_icon.py` (run it again after changing the art) and is
saved in `assets/icons/`:

| Platform | File | Notes |
| --- | --- | --- |
| Windows | `goban.ico` | 16–256 px in one file |
| macOS | `goban.icns` | Apple-style margin and shadow, up to 1024 px |
| Linux | `goban-<N>.png` | hicolor sizes 16–512 |

The running window always uses the icon. On Windows the app gets its own taskbar entry, so the
icon doesn't show up as Python's.

- **Linux menu entry:** `packaging/linux/install.sh` installs the icon and a "Goban" launcher for
  your user. Remove them with `--uninstall`.

## Stand-alone builds

To make a version that runs without Python installed, run this on the platform you're building
for (PyInstaller can't cross-compile):

```bash
pip install -r requirements-dev.txt
python packaging/build.py
```

| Platform | Result |
| --- | --- |
| Windows | `dist\Goban\Goban.exe` (no console window) |
| macOS | `dist/Goban.app` |
| Linux | `dist/Goban/Goban` |

Share the whole `dist/Goban` folder (or the `.app`), not just the program file. The Linux build is
about 100 MB.

- **macOS:** builds aren't signed, so on first launch right-click the app and choose **Open**.
- **Windows:** SmartScreen may show "Windows protected your PC". Click **More info**, then
  **Run anyway**.

## Keys

| Key | Action |
| --- | --- |
| `M` | mute / unmute music |
| `+` / `−` | music volume |
| `F11` (or `Ctrl`+`Cmd`+`F` on macOS) | fullscreen |
| `Enter` | send, in any chat box |
| `Esc` | leave a chat box / close the drawer or sign-in panel / back to the lobby |
| `Ctrl`+`Q` (`Cmd`+`Q` on macOS) | quit |

## Signing in

Sign-in uses the same username/password endpoint as the OGS website (`/api/v0/login`), then
fetches a realtime-socket JWT from `/api/v1/ui/config`. The password goes only to
online-go.com and is never written to disk. To sign in automatically, set `OGS_USERNAME` and
`OGS_PASSWORD` in the environment. Accounts that sign in through Google/GitHub etc. need an OGS
password set first.

## Layout

```
main.py              entry point
goban/app.py         window, scene switching, server-event routing
goban/net.py         REST session + realtime websocket ([command, data, id] JSON protocol)
goban/game.py        board reconstruction from gamedata, captures, clocks, ranks
goban/board_view.py  board/stone rendering and animations
goban/scenes.py      lobby, game screen (with game chat), sign-in overlay
goban/messaging.py   notifications, private messages and lobby chat state
goban/drawer.py      the messages drawer and pop-up toasts
goban/notify.py      desktop notifications for Windows, macOS and Linux
goban/settings.py    saved preferences (settings.json in the user data folder)
goban/ui.py          buttons, text fields, lists
goban/art.py         procedural textures (numpy)
goban/audio.py       procedural music and stone sounds (numpy)
goban/backdrop.py    animated sky
goban/paths.py       per-platform cache/data folders and bundled-asset lookup
tools/make_icon.py   renders the app icon in every format
packaging/build.py   stand-alone build for the current platform
packaging/linux/     Linux menu entry and installer
```
